Win Fast Finder — Fast Offline File Search for Windows

Any file, by name, in milliseconds — from one keyboard shortcut.

A lightweight, open-source filename search tool for Windows 10 and 11. It keeps an in-memory index of your filenames so a query returns instantly, without waiting on the Windows Search service. No cloud, no telemetry, no admin rights — and it never searches inside file contents, which is exactly what keeps it fast and private.

Why it exists

Windows Search is slow and can miss files. Most popular alternatives are closed-source or paywalled. Win Fast Finder answers one question — where is that file? — with MIT-licensed, fully auditable code.

  • Fast — typically single-digit millisecond queries over hundreds of thousands of cached names.
  • Offline & private — zero network code. The app cannot phone home because it has no code that does.
  • Non-admin — no kernel driver, no NTFS MFT reads, no background services.
  • Tiny — a ~240 KB app plus a single runtime prerequisite. Zero third-party dependencies.
  • Honest — every performance number published in the README is reproducible.

Where other tools beat us: NTFS-driver-based tools read the Master File Table directly, so their first index is faster. Win Fast Finder deliberately stays non-admin and portable — warm starts are instant thanks to a binary cache, but a first index walk over a huge tree takes longer. We would rather tell you that than hide it.

Install

Download win-fast-finder-Setup-1.0.1.exe from GitHub Releases, verify the SHA-256, and run it. The installer checks for the .NET 8 Desktop Runtime before copying anything. Requires Windows 10 (1607+) or Windows 11, x64 — no administrator rights to run the app.
